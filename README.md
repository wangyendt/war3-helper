# WSH魔兽助手 — U9WSH 复刻增强版

复刻经典魔兽争霸3辅助工具 **U9WSH（魔兽超级助手 v4.6, 2011）** 的全部实用功能，
无广告、无积分系统、无联网更新，并针对现代系统（Win11 / 高DPI屏）与任意魔兽版本做了升级。

程序位置：`bin\WshHelper.exe`（单文件，双击即用，配置自动存于同目录 `config.json`）

## 热键一览（魔兽窗口前台时生效）

- `Ctrl+F2` 改键开/关
- `Ctrl+F3` 切换改键方案
- `Ctrl+F4` 鼠标锁定开/关
- `Ctrl+F5` 血条/蓝条常显 开/关
- `Ctrl+F7` APM 悬浮窗开/关
- `Ctrl+F8` 计时提醒 开始/重新计时
- `Pause`（可改）老板键，任何时候可用

## 血条/蓝条常显是怎么做的

魔兽本身按住 `Alt` 就会显示所有单位的血条（DOTA 等地图同时显示蓝条）。本工具就是自动替你按住 Alt：

- 你一按键或点鼠标，**立刻松开 Alt**，所以不会变成 `Alt+点击`（DOTA 里那是发信号）或 `Alt+键` 组合；
- 停手约 0.3 秒后自动按回，血条随即恢复；
- 切出游戏自动释放，不影响其他程序。

**不注入游戏进程、不改游戏任何文件、不打内存补丁**，所以没有封号风险，也兼容任何魔兽版本。
另可一并开启游戏自带的"始终显示生命条"选项（写注册表 `Gameplay\healthbars`）。

> 原版 U9WSH 的显血显蓝走的是内存补丁路线，需要针对每个游戏版本适配，原版自己也提示"有被封号的风险"。

## 版本切换是怎么保证安全的

版本包（`版本X.zip`）之间的文件集合并不一致 —— 例如 1.24e 的包里**没有** `War3Patch.mpq`，
而 1.27 的包里带了自己的 `war3patch.mpq`。直接解压覆盖会导致切回 1.24 时补丁包丢失、游戏起不来。

所以切换流程是：

1. 换出前，把当前版本的**全部受管文件**（所有版本包里出现过的文件 ∪ War3.exe/Game.dll/Storm.dll/War3Patch.mpq）
   完整快照到 `<魔兽目录>\VersionStore\<版本名>\`；
2. 目标版本**优先从版本仓库还原**（仓库里是完整文件集），仓库没有的再从 zip 补齐；
3. 目标版本不需要、当前版本却有的受管文件，移到 `VersionStore\_disabled\`（不删除）；
4. 收尾校验补丁包是否存在，缺失会明确报错并告知还原路径。

非受管文件（`war3.mpq`、`War3x.mpq`、地图、存档、录像等）**全程不动**。
本仓库带一个沙箱测试验证来回切换不丢文件：

```bash
powershell -ExecutionPolicy Bypass -File build-test.ps1
```

切换前必须完全退出魔兽；若游戏装在受保护目录，请以管理员身份运行助手。

**关于"自动下载"**：可以在版本页填直链 URL 下载版本包（带进度、自动校验是不是有效 zip）。
本工具**不预置任何下载地址** —— 魔兽版本包属于游戏程序文件，请自行使用可信来源。
本机已有的 `war3ver` 版本包目录会被自动识别（含 1.20e ~ 1.27b 共 10 个版本）。

## 与原版 U9WSH 的差异

本工具用**系统级按键钩子**实现，不注入游戏进程、不读写游戏内存：

- ✅ 兼容任意魔兽版本（1.20~1.28），切换版本无需更新助手，无封号风险
- ✅ 对战平台中启动的魔兽同样自动识别（窗口类名 + 进程名双重匹配）
- ✅ 改键只在魔兽前台时生效，切出游戏不影响其他程序
- ❌ 未包含依赖内存注入的功能：AI 一键操作指令、JASS 脚本引擎

## 配置保存在哪

改键方案等配置存在 **`%APPDATA%\WshHelper\config.json`**，重新编译助手、删除 `bin\`、
重新 clone 仓库都不会丢。写入是原子的（先写临时文件再替换，并留一份 `.bak`），
中途崩溃不会损坏配置。喊话页有「配置文件位置」按钮可直接定位。

想让配置跟着程序走（绿色版），在 exe 旁边放一个空的 `portable.txt` 即可。
旧版本把配置放在 exe 目录，首次运行会自动搬到 AppData（原文件重命名为 `config.json.migrated` 留底）。

## NumLock：物品栏改键失效的头号原因

魔兽的物品栏快捷键是**小键盘 7 8 4 5 1 2**。而 NumLock 关闭时，这些键在系统层面压根就是别的键：

| 小键盘键 | NumLock 关 | NumLock 开 |
|---|---|---|
| 7 | Home | ✓ 小键盘7 |
| 8 | ↑ | ✓ 小键盘8 |
| 4 | ← | ✓ 小键盘4 |
| 5 | Clear | ✓ 小键盘5 |
| 1 | End | ✓ 小键盘1 |
| 2 | ↓ | ✓ 小键盘2 |

所以 NumLock 一关，所有指向物品栏的改键都会变成方向键，游戏里完全没反应
（只有映射到小键盘2的那个会让镜头下移，看着"像是有反应"）。

助手默认勾选「自动开启 NumLock」，检测到有改键指向小键盘且 NumLock 关闭时会自动打开它。
**键盘上没有 NumLock 键也没关系** —— 助手是用合成按键切换的，不需要物理按键。
改键页会实时显示当前状态。

## 在商店里不想改键怎么办

改键会把按键换掉，于是在商店里按原来的快捷键（比如 `S` 买树枝）就买不了了。
真正去判断「当前选中的是不是商店」必须读游戏内存，本工具刻意不做那件事，
所以提供三个**由你自己的操作来控制**的办法：

1. **商店模式**（推荐）—— 设一个「进入键」（可以直接用滚轮上/下）和一个「恢复键」（默认 F1）。
   滚一下滚轮就挂起全部改键，`S` 就还是 `S`；按 F1 重新选中英雄时自动恢复。
   状态栏和局内悬浮窗会提示当前处于商店模式。
2. **按住此键临时停用改键** —— 按住期间全部改键原样放行。
   （别选 `Tab`，魔兽里它是循环选择子编队。）
3. **物品键先选中英雄 (F1)** —— 只影响物品栏 6 个键，按下时先按一下 F1。

## 改键不生效时怎么排查

改键页最下方有「改键不生效时用这里排查」：

- **记录诊断日志** —— 勾上后进游戏按几下，回来点「打开日志」。日志逐条记录：按了什么键、
  有没有被改、发出了什么键、`SendInput` 的返回值。**返回值 0 = 注入被系统拒绝**，
  基本都是权限问题（魔兽以管理员运行而助手没有），把助手也用管理员身份运行即可。
- **注入方式** —— 默认「虚拟键 + 扫描码」；有些老游戏用 DirectInput 读键盘只认扫描码，
  可切到「只发扫描码」试试。
- **重装钩子** —— 手动重新挂接键鼠钩子。

## 低层钩子为什么需要看门狗

Windows 对低层键鼠钩子有 `LowLevelHooksTimeout` 限制（默认 300ms）：回调超时的钩子会被
系统**静默移除**，没有任何通知，之后所有事件都不再回调。

鼠标钩子每秒会被调用上千次（鼠标移动），最容易中招——表现就是「键盘改键还有效、
鼠标侧键/滚轮改键突然失灵」。为此：

- 回调里不做 `Marshal.PtrToStructure`（会装箱分配、制造 GC 压力），改为按偏移直读字段；
- 鼠标移动在读取任何字段之前就返回；
- 回调里不查进程信息（`Process.GetProcesses()` 要枚举全部进程），
  魔兽窗口句柄由**后台线程**每秒刷新好，UI 线程和钩子只读缓存。
  这一点特别关键：**低层钩子的回调运行在安装它的线程上，也就是 UI 线程** ——
  UI 定时器里任何耗时操作都直接堵在钩子回调前面。
- 看门狗 `WatchdogTick()` 双向检测：
  鼠标侧看「鼠标在动但回调没触发」；键盘侧主动注入一个未定义键(0xFF)的抬起事件做心跳，
  钩子活着就一定会被回调到。任一侧判定失效就自动重装，状态栏显示重装次数。

## 常见问题

- **局内悬浮图标 / APM 看不到**：独占全屏模式下任何悬浮窗都无法显示，请用默认的「无边框全屏」。
- **改键无反应**：确认魔兽不是以管理员身份运行；若是，把本助手也以管理员运行
  （权限低的进程无法向权限高的进程发送输入）。
- **喊话发不出来**：把喊话页下方的「发送速度」两个值调大。英文命令走真实按键最稳；
  中文靠 Unicode 注入，部分魔兽版本收不到。
- **在商店误买东西**：改键页勾选「物品键先选中英雄 (F1)」。

## 从源码构建

仅需 Windows 自带的 .NET Framework 4.x，无需安装任何 SDK：

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

> 注意：`build.ps1` / `build-test.ps1` 必须保持纯 ASCII。Windows PowerShell 5.1 会把无 BOM 的
> UTF-8 脚本按 ANSI 解码，中文注释被拆成的字节可能"吃掉"后面一行代码。

| 文件 | 职责 |
